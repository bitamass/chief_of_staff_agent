# Executive Dashboard Generation

## Purpose
Executive Dashboard Generation helps compress complex evidence into decision-ready executive briefing material.

## Instructions
1. Confirm the executive question, owner, and time horizon.
2. Use only dated, attributable evidence.
3. Normalize dated evidence, distinguish facts from inference, identify exceptions, and produce the specified executive work product.
4. Produce the executive dashboard specification defined in OUTPUTS.md.
5. State gaps, assumptions, and items requiring human review.

## Boundary
Cite sources, state limitations, and keep recommendations separate from facts.
