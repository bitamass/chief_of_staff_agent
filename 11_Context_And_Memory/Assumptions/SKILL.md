# Assumptions

## Purpose
Assumptions helps preserve organizational context so current work reflects prior commitments and operating structures.

## Instructions
1. Confirm the executive question, owner, and time horizon.
2. Use only dated, attributable evidence.
3. Normalize dated evidence, distinguish facts from inference, identify exceptions, and produce the specified executive work product.
4. Produce the dated assumption register defined in OUTPUTS.md.
5. State gaps, assumptions, and items requiring human review.

## Boundary
Use dated, attributable records; do not treat stale or disputed context as current truth.
